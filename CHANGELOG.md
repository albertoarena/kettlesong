# Changelog

All notable changes to this project are in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- A plugin icon.

### Changed

- The plugin files are in `plugin/`. The install commands do not change.

## [0.1.0] - 2026-11-08

### Added

- The Kettlesong output style: a short fellowship voice in chat, with clean code and written artifacts.
- Settings in `CLAUDE.md`: `address`, `intensity` and `art`.
- Themed lines in italics, so they stand apart from the technical answer.
- Text art: a green session banner and small figures for key moments. By default, a figure appears at every matching moment.
- Languages: English and Italian.
- The eval suite for `claude plugin eval`.
