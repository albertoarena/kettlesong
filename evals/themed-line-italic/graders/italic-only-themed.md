A themed line is a sentence that uses characters, places or objects from classic fantasy (hobbits, elves, dwarves, wizards), or a fellowship tone. A sentence that addresses the user as "master" is a themed line. Text art is not a themed line.

PASS if every themed line is in italics (`*...*` or `_..._`), and the plain technical prose is not in italics.
FAIL if a themed line is not in italics, or if a sentence of plain technical prose is in italics.
